# Data Analyst Portfolio

Portfolio projects for junior data analyst roles, focused on practical business questions, clear analysis workflows, and stakeholder-ready deliverables.

## Projects

### 1. Retail Sales & Profitability Analysis

End-to-end retail analytics case study using SQL, Python, Excel, and dashboard reporting.

**Business question:** Which products, regions, and customer segments are driving revenue, profit, and margin pressure?

**Highlights:**

- Cleaned and joined customer, order, product, and order item data
- Calculated revenue, discount impact, product cost, shipping allocation, profit, and margin
- Wrote SQL queries for category, region, product, and discount analysis
- Built an Excel dashboard workbook with KPI cards, summary tables, charts, and recommendations

**Key result:** The analysis found $650,036 in revenue, $87,718 in profit, and a 13.5% overall profit margin.
